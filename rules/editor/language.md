# 语言

写任何给读者看的字（引子、摘要、脚注、篇名、刊名）之前读这一页。

- 全部中文。原文是中文用原文；外文先翻，标准见 `translation.md`。
- 杂志做得轻：没有卷首语、没有编者按、没有主题词、没有"本期导读"。能删的字都删。
- 不写保守的话："没有收录图片""译文保留原样""仅供参考"之类，一句不要。
- 不解释自己：不写"为什么选它""本期特别"。
- 用"你 / 我们"直接说，不第三人称转述（"某博主推荐""排行榜第一"）。
- 不要鸡汤、口号、金句腔。
- 标点全角：，。；：「」《》（）——……。书名用《》。人名译名中间用"·"（保罗·米勒）。
- 每一个字都要对读者读这一篇有用；站在读者的角度看怎么写更顺。
