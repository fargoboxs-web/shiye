# 读者画像 reader.md

给谁看：AI 自己。挑书、选篇、写引子之前都先读它。读者不用填，也不用知道它存在。

## 字段固定，顺序固定

`reader.md` 只用下面六个二级标题，一个不多一个不少。没有内容的字段写"暂无"。模板在 `interfaces/schemas/reader.template.md`。

| 字段 | 写什么 |
|---|---|
| 基本 | 称呼（可以就是"你"）、读什么语言、笔记从哪来（Get笔记、小红书、手写……） |
| 关心 | 最近反复出现的主题，按出现次数排，每条一句，带"依据：N 条笔记" |
| 口味 | 喜欢怎样的文章（讲机制、讲故事、讲方法），讨厌什么（口号、清单、长铺垫） |
| 在读与读过 | 笔记里提到的书和作者，带时间；已经在读的不再选 |
| 禁忌 | 不选的题材、不用的语气、不碰的话题 |
| 变化 | 一行一条：日期｜什么变了｜依据哪条笔记（id 或标题）。只追加，不删 |

## 新建

第一次：读全部笔记，按六个字段写。每条判断标"（推断）"或"（原话）"。总长不超过 60 行。

## 更新：新的 context 进来就做

1. 读旧 `reader.md` 和新笔记。
2. 只改变了的字段：关心的热度、新出现的书、新的禁忌。没变的一字不动。
3. 在「变化」末尾加一行。
4. 不重写、不润色旧内容。读者自己说过的话优先于推断。

## 怎么判断"真的在意"

- 一整条笔记都在讲一件事，比顺口提到一句分量重。
- 跨多条笔记反复出现的书和主题，比只出现一次的重。
- 博主说"对我影响最大""改变了我的看法"的书，比书单里的普通一项重。
- 越新的收藏越能代表现在在想什么。
