# 封面

封面和封底由 `cover.json` 决定，渲染器只负责画。没有 `cover.json` 就按默认：fan 图案、按期轮换的配色、刊名用 `person.yaml` 的 `series` 或「拾页」。

## 风格：只到这一层

- 抽象几何，大面积留白，一个底色加少量形状。不用照片、不用插画、不用渐变。
- 封面上只有：图案、刊名、汉字日期；有 `series` 再加一行小字。没有目录、书影、期数。
- 封底和封面是一对：同一底色，同一图案镜像或同族，摊平后在书脊处拼起来。
- 能印出来：底色浅，形状色和底色有对比；家用打印机印大面积深色会发花。

## cover.json

| 字段 | 含义 | 不填时 |
|---|---|---|
| `title` | 刊名，两个字 | 必填 |
| `candidates` | 其他候选刊名 | `[]` |
| `series` | 封面小字，系列名 | 不印 |
| `palette` | 调色板名：淡紫、芥末黄、灰绿、淡粉；或自定义 `{"field": "#f3eef7", "shapes": ["#…", "#…", "#…"]}` | 按期轮换 |
| `motif` | `fan`、`stack`、`scatter`，或 `svg` | `fan` |
| `svg` | `motif` 是 `svg` 时的一段 SVG 片段，坐标系 148×210（单位 mm，左上为原点），封底自动镜像 | 无 |
| `seed` | 整数，决定形状的随机位置；换一个就变 | 期数，没有期数用日期 |
| `mast` | 刊名字体：`kai`、`song`、`hei` | `kai` |

格式见 `interfaces/schemas/cover.schema.json`。

## 怎么选

- 配色跟内容的温度走：讲方法和系统的偏冷（灰绿、淡紫），讲人和选择的偏暖（芥末黄、淡粉）。自定义配色要满足：底色明度高，三个形状色彼此可分、都比底色深。
- 图案跟刊名呼应，但不图解它。fan 是纸页展开，stack 是叠放的页，scatter 是散落的页：都是"页"的变体。
- 换两三个 `seed` 各排一次封面看看，挑一个。
