# 封面

封面和封底由 `cover.json` 决定，渲染器只负责画。没有 `cover.json` 就按默认：fan 图案、按期轮换的配色、刊名用 `person.yaml` 的 `series` 或「拾页」。

## 风格：只到这一层

- 抽象几何，大面积留白，一个底色加少量形状。不用照片、不用插画、不用渐变。
- 封面上只有：图案、刊名、汉字日期；有 `series` 再加一行小字。没有目录、书影、期数。
- 封底和封面是一对：同一底色，同一图案镜像或同族，摊平后在书脊处拼起来。
- 能印出来：底色浅，形状色和底色有对比；家用打印机印大面积深色会发花。

## cover.json

| 字段 | 含义 | 不填时 |
|---|---|---|
| `title` | 刊名，两个字 | 必填 |
| `candidates` | 其他候选刊名 | `[]` |
| `series` | 封面小字，系列名 | 不印 |
| `palette` | 调色板名：淡紫、芥末黄、灰绿、淡粉；或自定义 `{"field": "#f3eef7", "shapes": ["#…", "#…", "#…"]}` | 按期轮换 |
| `motif` | `fan`、`stack`、`scatter`，或 `svg` | `fan` |
| `svg` | `motif` 是 `svg` 时的一段 SVG 片段，坐标系 148×210（单位 mm，左上为原点），封底自动镜像 | 无 |
| `seed` | 整数，决定形状的随机位置；换一个就变 | 期数，没有期数用日期 |
| `mast` | 刊名字体：`kai`、`song`、`hei` | `kai` |

格式见 `interfaces/schemas/cover.schema.json`。

## 每期单独设计的封面（推荐）

读者的要求是：封面、封底每期重新设计，和这一期的内容呼应，不要每期套同一个图案只换颜色。上面的 `motif` 是兜底，认真做一期时这样做：

1. 读完全部选篇，写一句话：这几篇共同在讲什么。这句话只给自己看。
2. 从里面取一个能画出来的意象。例子：七篇都在讲事情表面之下的结构，刊名「底下」，图是七层地层，一层一篇。
3. 图里元素的个数等于篇数，每个元素的颜色就是那一篇的颜色，写进 `cover.json` 的 `layers`。封面、目录色带、篇首页就成了一套。
4. 出两三个方向的小样让读者挑。

做法：在期目录里放 `封面.html`、`封底.html`（各是那一页 `<section>` 里面的内容：一张整页 SVG 加刊名、日期两个 `<div>`，可以用 `{{ cfg.name }}`、`{{ cn_date[0] }}{{ cn_date[1] }}`）和 `封面.css`（接在样式表最后，用 `@page cover { background: … }`、`@page back { … }` 定底色，定刊名位置和字号）。有这三个文件就不画 `motif`。例子在 `examples/cover-strata/`。

`cover.json` 里和整期配色有关的字段：

| 字段 | 含义 | 不填时 |
|---|---|---|
| `layers` | 每篇一个颜色，按篇的顺序 | 都用封面底色 |
| `paper` | 封面底色，第一篇篇首页顶上那一条用它 | 调色板的底色 |
| `label_colors` | 「本期选读」和方案 B 序号的颜色，每篇一个 | 把 `layers` 自动压暗 |
| `style` | 篇首页排法 `A` 或 `B`，见 `../typesetting/divider.md` | `A` |

单独设计时封底不必是封面的镜像，底色也可以不同。屏幕颜色印出来会变暗变浊，橙和绿尤其明显，定色时往亮、往纯里偏一点。读者给了设计稿时量着稿子做，见 `../typesetting/covers.md`。

## 怎么选

- 配色跟内容的温度走：讲方法和系统的偏冷（灰绿、淡紫），讲人和选择的偏暖（芥末黄、淡粉）。自定义配色要满足：底色明度高，三个形状色彼此可分、都比底色深。
- 图案跟刊名呼应，但不图解它。fan 是纸页展开，stack 是叠放的页，scatter 是散落的页：都是"页"的变体。
- 换两三个 `seed` 各排一次封面看看，挑一个。
