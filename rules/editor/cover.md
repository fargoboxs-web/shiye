# 封面

封面和封底每一期由你设计，和这一期的内容呼应。没有现成的图案可套：期目录里没有封面文件，质检不通过。

## 风格：只到这一层

- 抽象几何，大面积留白，一个底色加少量形状。不用照片、不用插画、不用渐变。
- 封面上只有：图、刊名、汉字日期。没有目录、书影、期数。
- 封底和封面是一对：同一个意象的另一面，不必是镜像。底色可以相同，也可以不同。
- 能印出来：封面底色浅，形状和底色有对比。屏幕颜色印出来会变暗变浊，橙和绿尤其明显，定色时往亮、往纯里偏一点。

## 怎么想

1. 读完全部选篇，写一句话：这几篇共同在讲什么。这句话只给自己看。
2. 从里面取一个能画出来的意象。例子：七篇都在讲事情表面之下的结构，刊名「底下」，图是七层地层，一层一篇；六篇都在讲找到那个一推就动的地方，刊名「支点」，图是一根斜杠上六个球。
3. 图里元素的个数等于篇数，每个元素的颜色就是那一篇的颜色。封面、目录色带、篇首页就成了一套。
4. 意象要和刊名呼应，但不图解它。

## 怎么写

在期目录里放四个文件，照下面的写法写。`examples/cover-strata/` 是一个完整的例子，但它是照一份设计稿量着做的，画布、刊名位置都按稿子另写了 CSS，和下面的默认写法不一样；看它是为了知道能做到什么程度，不要照抄它的标记。

**`cover.json`**（格式 `interfaces/schemas/cover.schema.json`）

| 字段 | 含义 | 不填时 |
|---|---|---|
| `title` | 刊名，两个字 | 必填 |
| `candidates` | 其他候选刊名 | `[]` |
| `layers` | 每篇一个颜色，按篇的顺序。它会铺成篇首页的整块色块，上面压标题：深色块上标题自动反白，浅色块上是黑字，所以不要选半深不浅的颜色 | 必填 |
| `paper` | 封面和封底的底色 | `#F3EEE2` |
| `label_colors` | 「本期选读」几个小字的颜色，每篇一个 | 把 `layers` 自动压暗 |
| `divider_edge` | 篇首页色块的边：`straight` 直边，`wave` 波浪边。只有封面本身是波浪、地层这类意象时才用 `wave` | `straight` |

**`封面.html`、`封底.html`**：各是那一页里面的内容。

- 一张整页 SVG：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 148 210" width="148mm" height="210mm">`，一个单位就是 1mm。坐标自己算好写死，不用 `transform="rotate(…)"` 以外的技巧也行，但不要用渐变和滤镜。
- 封面的刊名和日期沿用模板的 class，位置和字体就是默认的（右上角竖排）：
  `<div class="mast"><div>{{ cfg.name[0] }}</div><div>{{ cfg.name[1:] }}</div></div>`
  `<div class="date"><span>{{ cn_date[0] }}</span><span>{{ cn_date[1] }}</span></div>`
- 封底放落款（左上角小字）：
  `<div class="colophon"><span>{{ cfg.name }}</span><span>{{ cn_date[0] }}</span><span>{{ cn_date[1] }}</span></div>`
- 质检从 `.mast` 读刊名，封面和封底都要有汉字日期。

**`封面.css`**：接在样式表最后。不改位置就留空文件。想挪刊名、改字号，写 `.cover .mast { … }`、`.cover .date { … }`（封底是 `.backcover`）；封底想用别的底色，写 `@page back { background: … }`。

## 看一眼再定

`run.py render` 之后跑 `run.py covers`，封面和封底会存成图放在期目录的 `小样/` 里。自己看：元素有没有出界、挤不挤、刊名压没压到图。不满意就改文件重排，最多三轮。再翻一遍每篇的篇首页，确认色块上的标题看得清。

用户给了设计稿时量着稿子做，见 `../typesetting/covers.md`。
