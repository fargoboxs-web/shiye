# 导语

篇首页上那段楷体字，以前叫引子。不加标签。

只回答一个问题：为什么这一期选了这一篇。

- 三四句，平铺直叙，只用原文和笔记里有的事实。通常 80–200 字，上限 600 字。
- 从哪来：笔记原话。`why_saved` 里有笔记 id，要回原文看，不凭摘要猜。读者自己说过为什么想读这本书，就用他的话，这是最好的导语。
- 不概括这一章的内容。读完导语还得想读正文。
- 不要这些写法，读者管它们叫「AI 味」：
  - 反问开头；
  - 「不是……而是……」的翻转；
  - 凑三项的排比；
  - 格言式的结尾；
  - 用「你」预设读者的处境（「你做了一个东西……」）。
- 不写出处（谁推荐、排第几），不评价。
- 一期里每篇导语的句式不要一样。写完把几篇并排读一遍，像一个模子出来的就重写。
- 自查：有没有哪一句是为了显得有文采而写的？删掉它少了什么信息吗？没少就删。
