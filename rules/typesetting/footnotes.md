# 脚注版式

依据：新闻出版行业标准 CY/T 121—2015《学术出版规范 注释》和《学术出版规范 一般要求》，加上国内图书的通行做法。内容怎么写见 `../editor/footnotes.md`。

- 位置：本页底部，按正文里出现的先后排。脚注线左齐，长度是版心宽度的 1/4（CY/T 121 第 5.3 条），线上留 4mm、线下留 2mm。
- 注码：圈码①②③。正文里上标、略小；注文开头的圈码用正文字体、不上标（《一般要求》）。每篇文章从①重新编号。
- 字号：注文比正文小一号——正文五号 10.5pt，注文小五号 9pt，宋体，和正文同一种字，行距 1.5。颜色和正文一样，不用别的颜色。
- 对齐：注文悬挂缩进，回行和首行的文字对齐，圈码悬在外面。圈码后面是定宽空隙，不参与两端对齐的拉伸。
- 实现：`selection.json` 的 `notes` 在排版时挂在正文第一次出现那个词的地方（`float: footnote`）；WeasyPrint 的脚注区背景用带固有尺寸的 SVG 画线，不用渐变（渐变会铺满整个区域）。
