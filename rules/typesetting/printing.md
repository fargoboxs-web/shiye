# 打印

- PDF 是 A5。印成 A5 用 100% 不缩放；用 A4 纸就「每张两页」或「小册子」模式，一张 A4 正好两页 A5，字号不变。不要把一页 A5 放大到整张 A4：正文会变成约 14.8pt。
- 书影阴影直接画进图片（`zine/render.py` 的 `shadowed`：封面 700px 加 60px 边、高斯模糊的偏移阴影、一圈细线），PDF 里就是一张位图，什么软件打开、什么打印机都一样。不用 CSS 的 `box-shadow`，苹果「预览」会把它画成黑边。内页不用任何透明（ExtGState ca/CA 都是 1）。
- 骑马钉：config 里 `pad_to_4: true` 时用笔记页把总页数补成 4 的倍数；默认不补。
- 封面底色浅、形状不透明，普通彩色打印机就能印；送厂时按 A5 成品、不留出血，封面封底各自一页。

## 送打印店（读者印过三期的经验）

- A5 胶装，封面覆膜选**哑膜**。亮膜反光，颜色显得更浊。
- 总页数 80–100 页。82 页手感最好，123 页拿着偏重。
- 屏幕是 RGB，印刷是 CMYK，橙、绿、紫会变暗变浊。封面定色时留余量，重要的一期先印一本看样。
- 打印店通常把封面单独印，内页从 PDF 第 2 页开始装订。现在的 PDF 是「封面 → 目录 → 第 1 篇篇首页」，直接交会出两个问题，都遇到过：
  1. **页码落到订口一侧**。封面拿走后目录成了第 1 页（右页），第 1 篇篇首页落在它背面，之后所有左右页都反了。交印前要让目录背面单独占一页，第 1 篇篇首页回到右页，内页总页数为偶数。引擎还没自动处理（见 README「还没做的」）。
  2. **封底图案包到封面上**。只给单页时店家自己拼封面展开图，书脊宽度对不准，封面左缘会露出一条封底的图案。办法：自己出一张展开图（封底 + 书脊 + 封面，四周各 3mm 出血），书脊宽度问店家（约等于内页张数 × 纸厚，80g 纸一张约 0.1mm）；书脊和封面交界处两侧用同一种颜色。
