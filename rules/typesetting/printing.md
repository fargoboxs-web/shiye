# 打印

- PDF 是 A5。印成 A5 用 100% 不缩放；用 A4 纸就「每张两页」或「小册子」模式，一张 A4 正好两页 A5，字号不变。不要把一页 A5 放大到整张 A4：正文会变成约 14.8pt。
- 书影阴影直接画进图片（`zine/render.py` 的 `shadowed`：封面 700px 加 60px 边、高斯模糊的偏移阴影、一圈细线），PDF 里就是一张位图，什么软件打开、什么打印机都一样。不用 CSS 的 `box-shadow`，苹果「预览」会把它画成黑边。内页不用任何透明（ExtGState ca/CA 都是 1）。
- 骑马钉：config 里 `pad_to_4: true` 时用笔记页把总页数补成 4 的倍数；默认不补。
- 封面底色浅、形状不透明，普通彩色打印机就能印；送厂时按 A5 成品、不留出血，封面封底各自一页。
