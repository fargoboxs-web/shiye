# 页面

- A5（148 × 210mm）。天头 20mm，地脚 18mm，左右 16mm。内页白底（插图多是白底，米色纸会露出一圈白）。
- 页眉：页码在外上角，旁边一行小黑体——双页（左）是本期刊名，单页（右）是本篇书名。页码就是普通数字，不加色块。扉页、目录、封面、封底没有页眉页码。
- 每本书一页扉页，正文从下一页起。扉页要素顺序固定：书影、序号、《书名》、作者、年份与译者、原书名、引子、「本期选读」、章节标签、摘要。书影带一圈柔和阴影，阴影画在图片里（见 `printing.md`）。
- 目录单独一页（第 2 页）：序号、篇名、《书名》作者、页码，细线分隔，不加别的装饰。
- 不为了左右页硬插空白页，也不补页凑 4 的倍数；要印骑马钉时在 config 里打开 `pad_to_4`。
- 不在任何地方写「第 N 期」。日期用汉字（二〇二六年　十月），只在封面和封底出现。
- 页型序列固定：封面 → 目录 →（扉页 → 正文）× N →（笔记页 0–3）→ 封底。
