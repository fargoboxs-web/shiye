# 封面、封底的版式

封面和封底每期由 agent 设计（做法见 `../editor/cover.md`），这里只写不随设计变的部分。

## 固定的

- 刊名两个字，楷体，默认右上角竖排 58pt（距右 16mm、距上 17mm）；日期用汉字，8pt 宋体。不写「第 N 期」。
- 封面只有图、刊名、日期。没有目录、书影、期数。
- 封底有落款：刊名和汉字日期，小字。不放书目。
- 形状不透明，不用渐变，送厂不用拍平透明。
- 封面和书脊交界处两侧用同一种颜色，装订偏一点也看不出来（见 `printing.md`）。

## 有设计稿时

用户或设计师给了定稿（PDF）时，量着稿子做，不凭印象重画，也不顺手「改进」：用 PyMuPDF 读出每个色块的路径、每行字的字号、位置、颜色，照抄进封面文件；改完把原稿一页和成品一页分别放进红、青两个通道叠成一张图看，重合处是灰的，错位处有色边，偏差控制在 0.5mm 内。回答「是不是都照做了」之前先做这张图。

目录和篇首页的版式见 `divider.md`。
