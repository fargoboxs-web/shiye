# 字号、行距、段距

依据：中国字号表、W3C《中文排版需求》（clreq）、参考纸书《选择的悖论》实测。clreq 不规定具体数字，数字按惯例定。

## 字号表（模板 `templates/issue.html` 的数值）

| 位置 | 字体 | 字号 |
|---|---|---|
| 正文 | 宋体 | 10.5pt（五号） |
| 引文（楷体段） | 楷体 | 10pt，左缩进 2 字、右缩进 1 字 |
| 节标题 | 黑体 | 11.5pt，加粗，居中，上空 7mm 下空 3.5mm |
| 小节标题 | 黑体 | 10.5pt，加粗，靠左 |
| 篇名（正文第一页） | 黑体 | 16pt（三号），加粗 |
| 扉页书名 | 黑体 | 20–22pt，加粗；长书名在「与」后换行，再长缩到一行 |
| 扉页引子 | 楷体 | 10.5pt |
| 扉页摘要 | 宋体 | 10pt，行距 1.7 |
| 方框栏目 | 宋体 | 9.5pt，框标题黑体 10pt 居中 |
| 脚注 | 宋体 | 9pt（小五），行距 1.5 |
| 图注 | 黑体 | 8.5pt，居中 |

中国字号表：初号 42、小初 36、一号 26、小一 24、二号 22、小二 18、三号 16、小三 15、四号 14、小四 12、五号 10.5、小五 9、六号 7.5、小六 6.5、七号 5.5（pt）。书刊正文通常五号或小四。

## 行与段

- 行距取字号的 1.75 倍（10.5pt 字、约 18.4pt 行距）。《选择的悖论》纸书实测约 1.7 倍。
- 每行约 31 个汉字（A5，左右各 16mm）。书刊正文每行 25–35 字为宜。
- 段首缩进两个字。段间空 0.7 字高（纸书接近一行，这里取小一点，页数不会涨太多）。
- 汉字与字母、数字之间留 1/4 字宽（clreq 3.2.2）。WeasyPrint 不支持 text-autospace，渲染时自动插定宽空盒子。
- 字母之间不加字距。只有页眉和栏目标签这类很小的黑体加一点字距。
