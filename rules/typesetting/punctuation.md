# 标点与中西文间距

- 全部用全角标点：，。；：「」《》（）——……
- 并列信息用逗号或书名号表达关系，不用「·」之类的圆点。圆点只在译名中间用（保罗·米勒）。
- 全刊只用一种引号（「」，内层『』）。电子书里的 “” ‘’、台版的竖排引号、译名里的全角句点（保羅．米勒）、制表线破折号（──）、年份里的 ○，`prepare` 和 `render` 都会归一，不用手改；引子、摘要、脚注、译文直接按这个体例写。
- 强调用着重号（字下加点），不用斜体，中文没有斜体。
- 行首不出现句号、逗号、下引号，行末不出现上引号（禁则，排版引擎自动处理）。
- 汉字与字母、数字之间留 1/4 字宽（clreq 3.2.2），渲染时自动插入。
- 括号里的西文人名，词间空格不参与两端对齐的拉伸（渲染时换成定宽空盒子）。
